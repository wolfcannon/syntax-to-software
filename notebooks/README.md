# Notebooks

Your own work goes here. The course expects one file to start with —
`exploration.ipynb` — created in step 1, and it stays exploration-only from
step 14 onward, once the logic moves into a module.

Nothing in this directory is checked by the exercise harness. The browser
exercises verify that you can do each thing; the notebook is where you do it
to the whole dataset, which is a different and more interesting problem.

If you don't have Jupyter yet: `pip install jupyterlab`, then `jupyter lab`.
Step 18 sets up a virtual environment properly, and explains why doing it
before then would have been teaching you two things at once.
