A 23-step course

From Syntax to Software

Learning Python by building one real thing: an analysis of whether neighbourhood walkability predicts bike commuting — and what explains the places that don't fit the trend.

This is a course for someone with a strong mathematical background and no Python experience, aimed at data work. Every step teaches one layer of the language or of the development process, and every step advances the same project. There are no toy exercises about animals and shapes; by step 4 you are building Census block group identifiers, and by step 8 you are diagnosing why 12 of them failed to join.

The research question

Does neighbourhood walkability predict bike commuting, and what explains the places that don't fit the trend?

Scope: Marion County, Indiana (state FIPS 18, county FIPS 097) — 632 census block groups, already in this repo. The capstone scales it up.

How the course works

Two halves that do different jobs:

  • These pages explain the ideas and check your work. The exercises run Python in your browser — nothing is uploaded, nothing is installed, and there is no account. Your answers and progress are remembered locally on this machine.
  • The notebooks and scripts in this repo are where the real project lives. From step 13 onward the work moves permanently out of the browser and onto your own machine, because installing packages, reading files, calling an API, using git and running tests is the subject matter from that point on.

About the hidden checks

Each exercise runs your code and then runs a handful of assertions you don't see. That is deliberate. In step 20 we stop hiding them — the harness that has been grading you all along turns out to be a few dozen lines of pytest, and you start writing your own.

Getting started

The exercises need the page served over HTTP rather than opened straight off the disk, which takes one command you already have:

git clone <this repo>
cd syntax-to-software
python3 -m http.server 8000
# then open http://localhost:8000

The first exercise you run downloads the Python runtime (Pyodide, about 10 MB) from a CDN, so step 1 needs an internet connection. After that the browser caches it. Nothing else phones home.

One honest caveat

The walkability data is real, pulled from the EPA. The commute data is currently synthetic — shaped exactly like the real API response, with a plausible relationship to the real walkability scores, but generated rather than measured. Everything you learn from Units 1–3 is unaffected; the capstone's findings are not meaningful until it is replaced. README.md has the three commands that replace it, and they need a free Census API key.

They do not line up perfectly, and that is the point: 7 block groups have a walkability score and no commute data, 5 have commute data and no walkability score, 14 have no workers at all, and 9 carry the Census "estimate unavailable" sentinel -666666666. You meet all four of those in Unit 1.

The 23 steps

Unit 1 — Foundations (steps 1–9, available now)

Read, represent, and transform the project data using only the core language. No third-party packages, no files — the data arrives as a literal you can read with your eyes.

Unit 2 — Correctness (steps 10–13)

Equivalent forms of the same computation; reading tracebacks; refactoring while proving the output didn't change; exceptions and the failure modes this data actually has; and finally real files, which retires the sample cell for good.

Unit 3 — Structure and the ecosystem (steps 14–17)

Modules, classes and dataclasses, choosing third-party packages (pandas, matplotlib, scipy — and rebuilding the hand-written join to check it), and talking to the Census API yourself.

Unit 4 — Development practice (steps 18–23)

Virtual environments, a multi-file project, git, pytest, the reproduce→test→fix→commit cycle run against two realistic tickets, project layout, and a capstone that answers the research question honestly — margins of error included.

Needed later, not now

Step 17 has you call the Census API yourself, which needs a free key from api.census.gov. Steps 1–16 do not.
