Control structures

Branching and looping, and the boundary conditions that turn a tidy classification into an off-by-a-hundredth bug.

if / elif / else

Only the first matching branch runs, and elif is not decoration — a chain of separate ifs can fire more than once and give a different answer:

if score <= 5.75:
    label = "Least Walkable"
elif score <= 10.5:          # reached only if the first was False
    label = "Below Average"
else:
    label = "Above Average"

Because earlier branches have already excluded the lower ranges, each test only needs its upper bound. Writing elif 5.76 <= score <= 10.5 is not wrong, but it states a condition that is already guaranteed — and it is how gaps sneak in.

Loops, and leaving them early

for walks a sequence; while repeats until a condition goes false. Inside either, continue skips to the next iteration and break abandons the loop entirely.

for row in joined:
    if row["workers"] == 0:
        continue            # no workers: no share exists. Skip, don't zero.
    share = row["bike"] / row["workers"]

That continue is doing analytical work, not just avoiding a ZeroDivisionError. A block group with no workers has no bike share to contribute; including it as 0% would pull the mean down on the strength of no evidence at all.

Truthiness

Python will treat almost anything as a condition: 0, 0.0, "", [], {} and None are false, and essentially everything else is true. That makes if rows: a neat way to say "if there are any rows".

Where truthiness betrays you here

if row["walk_index"]: is not the same as if row["walk_index"] is not None:. A perfectly valid score of 0.0 would be treated as missing. Walkability starts at 1 so you would get away with it — but bike counts start at 0, and there the same shortcut silently discards every block group where nobody cycles, which are precisely the rows the analysis is about. Use is None when you mean missing.

Does a score of exactly 10.5 land in the right bucket?

Only if you wrote <=. With score < 10.5, a score of exactly 10.5 falls through to the next branch and is reported as Above Average, when the EPA calls it Below Average.

It matters more than one row usually would, because the index is built by averaging four integer ranks — so scores land on clean fractions far more often than continuous data normally would. 10.5 is (a+b+c+d)/4 for plenty of integer combinations, and 14.5 appears in your sample data.

The general habit: whenever you write a threshold, immediately ask what happens at it. That question has a permanent home in step 20, where 5.75, 10.5 and 15.25 become parametrised test cases and stop depending on anyone remembering.
