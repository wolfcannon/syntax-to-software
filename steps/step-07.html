Unit 1 — Foundations · Step 7

Loops

  • Do the same thing once per item, without writing it out.
  • Build up an answer as you go.
  • Skip an item, or stop early, when the data says so.

for

A for statement opens a block and runs it once per item in a sequence, binding a name to each item in turn.

scores = [3.5, 14.5, 9.0]

for score in scores:
    print(score)

The name after for is yours to choose. It exists only because the loop put a value in it, and it is rebound on every pass — which is step 2's referential binding, happening automatically.

A range works the same way, which is what makes it useful for counting rather than for holding data:

for i in range(3):
    print(i)        # 0, then 1, then 2

Building up an answer

Most loops exist to accumulate something. Start with an empty answer before the loop, add to it inside, and read it afterwards.

scores = [3.5, 14.5, 9.0]

total = 0
for score in scores:
    total = total + score

print(total / len(scores))   # 9.0 — the mean

Where the accumulator is set matters. Inside the block it would be reset on every pass; after the block it would not exist yet. This is the indentation lesson from step 4 with something at stake.

Leaving a loop early

Two statements interrupt the normal run of a loop. continue abandons this pass and starts the next. break abandons the loop entirely.

for score in scores:
    if score is None:
        continue          # no score here — on to the next one
    print(score)

A continue is a decision about the data

Skipping a neighbourhood with no score is not the same as counting it as zero. Zero drags a mean down on the strength of no evidence; skipping leaves it out of the question entirely.

Either can be right. What is never right is skipping without counting how many you skipped, which is exercise 1.

while

for walks a sequence you already have. while repeats for as long as a condition stays true, which means you need to be sure the condition eventually goes false.

countdown = 3
while countdown > 0:
    print(countdown)
    countdown = countdown - 1

Delete that last line and the condition never changes, so the loop never ends. Reach for for unless you genuinely do not know how many passes you need.

Exercises

Tip 💡: three questions for every loop you write

  1. What is the answer before the loop starts? Write that line first.
  2. Is each line inside the block or after it? One of them is almost always wrong the first time.
  3. What did you skip, and did you count it? A loop that quietly drops rows is how a result ends up describing a population you did not mean.
